操作行为
🎙 补录配音进入配音模式：画面连播，你跟着说，橙色配音轨实时生长；再点一下结束。可多段补录，导出自动合入
轨头（系统声/麦克风/配音）点名字弹音量条（0–200%）+ 静音按钮；某轨太吵/太小现场调
💬 自动字幕有配音或麦克风轨后可用：设备端语音识别生成字幕轨（绿色条），画面底部同步显示；播放走一遍校对
字幕条点字幕条可改文案（原型未演示）；成片导出时烧录进画面
建议做的：补录配音（命中你说的"后期加口述"）、每轨音量/静音、自动字幕（你机器 macOS 26 支持本地识别带时间戳）
两个代价要想清楚：① 字幕烧录导出需要重新编码（不再直通秒级，47 秒视频约十几秒）；无字幕时仍走直通 ② 自动字幕仅 macOS 26+ 可用，旧系统隐藏该按钮
不建议做的：手动逐条打字幕（费劲，价值低）、花字/贴纸/转场（超出"录完快修"定位）。确认这个边界 OK 我就按 v3 实现 App 版。

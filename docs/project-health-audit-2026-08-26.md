## 已修正

1. 清理便签和符号功能中可能把用户正文、符号内容或通知参数写进控制台的调试日志，仅保留长度和状态信息。
2. 去除便签文本容器的一处强制解包。
3. 修正剪贴板历史 Core Data 在 `@MainActor` 上重复进入 `performAndWait` 产生的 Swift 6 隔离警告。
4. 修正剪贴板面板失焦通知跨 Actor 调用 UI 的问题。
5. 将录屏引擎和配音录制器的锁操作收敛到同步锁域，避免 Swift 6 禁止在 async 上下文直接 `lock/unlock`。
6. 冻结录屏资产分析结果后再交给 MainActor，避免可变捕获跨并发域。
7. 修正字幕合成器属性的 Sendable 类型、OCR/Vision 并发导入、废弃 Core Data 索引 API，以及若干无效绑定/多余 `await`。
8. 去掉托管对象映射中的无效 nil fallback，保持模型类型与代码一致。

2. 录屏人工回归：分别测试无声、仅系统声、仅麦克风、双音轨；再覆盖暂停/恢复、立即停止、取消、配音、字幕和导出。此次重构保持原锁域语义且测试全绿，但实时媒体链路仍应做真机冒烟。
3. 剪贴板人工回归：首次打开、历史升级加载、搜索、置顶、删除、清空、保留策略、加入闪记、直接粘贴权限缺失时的降级流程。
4. 多屏人工回归：主屏/副屏分别截图和录屏，覆盖不同缩放比例、窗口跨屏和保存目录书签失效。

### P1：国际化

系统语言选择与中英文资源框架已经存在，但 SwiftUI 中仍有约 277 处直接中文 UI 字面量。它们不会阻止本次中文版本审核，但会导致国际区用户看到中英混杂。建议按“主面板 → 剪贴板 → 截图/录屏 → 设置 → 便签/符号”的顺序迁移到 `Localizable.strings`，并给关键页面补英文快照或字符串完整性测试。

### P2：发布工程

1. 主应用 target 当前没有 `PrivacyInfo.xcprivacy`；仓库里的两个 manifest 属于 ScrollSnap 研究子项目。下次版本应先盘点 required-reason API 和第三方 SDK，再决定并补齐主 target 的隐私清单。
2. 仍有一批强制解包，主要是“系统必有屏幕/应用支持目录”“非空几何数组”和 Preview 假设。建议逐模块收敛，优先处理启动路径和截图主流程，Preview 可后置。
3. `LongScreenshotFlowController` 明确标注当前只采集并保存原始帧、不做最终拼接；入口目前没有从正式 UI 对外触发。继续保持隐藏，直到补齐拼接、导出、失败恢复和端到端测试。
4. 调试输出仍偏多。后续应将关键链路统一迁移到 `DiagnosticCenter`，并确保生产日志只记录状态、计数、匿名 ID 和错误类型，不记录正文或自定义配置内容。

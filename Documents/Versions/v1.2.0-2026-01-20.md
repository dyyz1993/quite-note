## 🔧 技术细节

### 键盘事件优先级

```
First Responder.keyDown (高优先级)
    ↓
Local Monitor (低优先级)
    ↓
其他事件处理器
```

**结论**：必须使用 First Responder 回调，不能用 Local Monitor

### SwiftUI 状态更新模式

```swift
// ❌ 错误：Binding(get:set:) 不会触发更新
Binding(
    get: { manager.someValue },
    set: { manager.someValue = $0 }
)

// ✅ 正确：@ObservedObject + @Published
class State: ObservableObject {
    @Published var someValue: Int = 0
}

@ObservedObject var state: State
```

### NSPanel styleMask 对比

| styleMask | 特点 | 适用场景 |
|-----------|------|---------|
| `[.borderless]` | 可成为 key window，键盘事件正常 | 需要键盘交互的面板 ✅ |
| `[.borderless, .nonactivatingPanel]` | 不会成为 key window，键盘事件异常 | 不需要键盘的提示性面板 |

## ⚠️ 注意事项

1. **焦点管理** - 面板打开时焦点保持在主窗口文本编辑器
2. **多窗口** - 符号只插入到触发面板的窗口（通过 UUID 匹配）
3. **状态重置** - 每次打开面板时重置状态，避免旧状态残留
4. **ESC 协调** - 面板打开时 ESC 传递给面板，关闭时才传递给主窗口

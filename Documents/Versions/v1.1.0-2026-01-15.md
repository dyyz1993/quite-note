# Quite Note v1.1.0 更新日志

**发布日期：** 2026-01-15

## 🎉 主要更新

### 1. 原文框优化

#### 卡片折叠间隙修复
- 🐛 修复点击原文后折叠卡片导致的间隙过宽问题
- 📐 卡片折叠时自动清除原文展开状态
- 🎯 优化卡片展开/折叠逻辑，确保状态同步

#### 图片类型原文框调整
- 📏 缩小图片类型原文框高度（120-250px）
- 🚫 移除图片类型展开后的自动滚动
- ✨ 改善图片类型记录的浏览体验

#### 快速复制功能
- 📋 在未展开且有 AI 摘要时显示快速复制按钮
- ⚡ 一键复制原文内容，无需展开卡片
- 💡 复制成功后显示触觉反馈和提示

### 2. UI 优化

#### Space 固定状态指示器
- 📌 优化 Space 固定状态显示方式
- 🎯 改为右上角小图标显示（绿色实心图钉 = 固定到所有 Space，灰色空心图钉 = 当前 Space）
- 🚫 从工具栏移除，界面更简洁

#### 工具栏 Tooltip 修复
- 🔨 使用自定义 tooltip 替代 SwiftUI `.help()` modifier
- 🎯 修复截图窗口层级导致的 tooltip 不显示问题
- ✨ 优化 tooltip 显示效果，2秒后自动消失

#### Icon 缓存清除
- 🗑️ 添加图标缓存清除功能
- ⚙️ 在设置→符号库中添加"重载图标"按钮
- 🐛 Debug 模式下禁用图标缓存，实时更新修改

### 3. 核心功能

#### Cmd+Z 撤销/重做
- ↩️ 新增应用级别撤销/重做功能
- 📝 支持撤销：删除记录、编辑内容、切换星标
- ⌨️ 快捷键：`Cmd+Z` 撤销，`Cmd+Shift+Z` 重做
- 📊 最多记录 50 个历史操作
- 🎯 自动处理文本编辑器撤销优先级

#### 同路径文件自动更新
- 🔄 拖入相同路径文件时自动更新现有记录
- 💡 显示"已更新现有文件"提示
- 🚫 避免重复创建相同文件的多条记录

## 🚀 使用指南

### 快捷键列表

| 快捷键 | 功能 |
|--------|------|
| `Cmd+Z` | 撤销（删除/编辑/星标） |
| `Cmd+Shift+Z` | 重做 |

### 清除图标缓存

1. 打开设置 → 符号库
2. 点击底部的"重载图标"按钮
3. 图标缓存将被清除并重新加载

### Space 固定状态

- 📌 **绿色实心图钉**（右上角）= 固定到所有 Space
- 📍 **灰色空心图钉**（右上角）= 仅当前 Space

### 撤销/重做支持的操作

- ✅ 删除记录
- ✅ 编辑便签内容
- ✅ 切换星标状态

## ⚠️ 注意事项

1. **撤销优先级** - 文本编辑器撤销优先于应用级别撤销
2. **历史限制** - 最多记录 50 个操作，超出后自动删除最旧记录
3. **图标缓存** - Debug 模式下图标不会被缓存，每次重新加载

## 🔄 升级说明

从 v1.0.8 升级到 v1.1.0：

1. **数据兼容** - 完全兼容，无需数据迁移
2. **设置保留** - 用户设置全部保留
3. **无需手动操作** - 直接替换应用即可

## 🚀 使用指南

### 创建自定义符号库

1. 打开设置 → 符号库设置
2. 点击"创建新配置"按钮
3. 自动在 VS Code（或默认编辑器）中打开 YAML 模板
4. 编辑配置文件，修改符号、触发词等
5. 保存文件
6. 点击"加载配置"按钮

### 符号库配置示例

```yaml
metadata:
  name: "我的符号库"
  icon: "⭐"
  priority: 10
  enabled: true

global:
  trigger_prefix: ":m"    # 触发前缀
  auto_hide: true
  auto_clean: true

symbol_menus:
  - title: "常用符号"
    sort: 1
    icon: "⭐"
    symbols:
      - trigger: ["ok", "好的"]
        content: "✅"
        desc: "完成/通过"
```

## ⚠️ 注意事项

1. **触发前缀冲突** - 创建新配置时避免使用已存在的前缀（`: /` 和 `:e`）
2. **默认配置保护** - 默认符号库和 English Symbols 不可删除
3. **配置文件位置** - 用户配置保存在 `~/Library/Application Support/QuiteNote/Symbols/`
4. **YAML 格式** - 使用标准 YAML 语法，注意缩进和引号

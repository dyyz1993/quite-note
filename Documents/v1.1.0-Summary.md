## 📋 需求清单

### 优先级 P1 - 原文框相关（影响日常使用）

#### 1. 点击原文后没有折叠，直接折叠卡片导致间隙过宽
**问题描述：**
- 点击原文展开后，再点击卡片折叠（header 或展开按钮）
- 卡片折叠了，但底部 130px padding 残留，导致间隙过宽

**根本原因：**
- `expandedId` 控制卡片展开/折叠
- `originalContentExpandedIds` 控制原文展开状态
- 两个状态独立，卡片折叠时没有清除原文展开状态

**解决方案：**
```swift
// RecordCardView.swift - 卡片折叠时同步清除原文状态
if isExpanded {
    expandedId = nil
    if showOriginalContent {
        showOriginalContent = false
        NotificationCenter.default.post(
            name: Notification.Name("OriginalContentToggled"),
            object: ["recordId": record.id, "isExpanded": false]
        )
    }
}
```

---

#### 2. 图片类型的原文框太长，且会自动滚动
**问题描述：**
- 图片类型原文框 `minHeight: 350, maxHeight: 650` 太高
- 展开后自动滚动到原文底部，体验不佳

**解决方案：**
```swift
// 1. 缩小图片类型原文框
.frame(
    minHeight: record.type == .screenshot ? 150 : 200,
    maxHeight: record.type == .screenshot ? 300 : 400
)

// 2. 图片类型跳过自动滚动
if record.type != .screenshot && record.type != .image {
    proxy.scrollTo(originalContentId, anchor: .bottom)
}
```

---

#### 3. 希望原文可以直接复制，无需展开
**用户场景：**
- 有时只想快速复制原文内容，不需要展开查看

**解决方案：**
- 在未展开且有 AI 摘要时，显示快速复制按钮
- 使用 `.copy` 图标，点击直接复制到剪贴板
```swift
if !isExpanded && record.summary != nil {
    Button(action: {
        NSPasteboard.general.clearContents()
        NSPasteboard.general.setString(record.content, forType: .string)
        HapticFeedbackManager.shared.lightImpact()
        store.postLightHint("已复制原文")
    }) {
        LucideView(name: .copy, size: 12, color: .themeTextSecondary)
    }
}
```

### 优先级 P2 - UI/问题修复

#### 4. 工具栏 tooltip 看不到，但能上下动
**问题描述：**
- 截图窗口使用 `.screenSaver` 级别（最高优先级）
- SwiftUI `.help()` modifier 在此窗口层级下不显示

**解决方案：**
- 使用自定义 tooltip 替代 `.help()`
- 添加 `@State` 状态管理 tooltip 显示
- `GeometryReader` 获取按钮位置，`.onHover` 触发显示

```swift
@State private var tooltipText: String = ""
@State private var showTooltip: Bool = false

.onHover { hovering in
    if hovering {
        tooltipText = "保存到闪记 (Command+S)"
        withAnimation { showTooltip = true }
    }
}
```

---

#### 5. 修改 icon 后 note 没有实时能用
**问题描述：**
- `Icon.swift` 使用 `NSCache` 永久缓存图标
- 没有缓存失效机制
- Bundle 扫描只执行一次

**解决方案：**
```swift
// Icon.swift
static func clearCache() {
    iconCache.removeAllObjects()
    foundBundles.removeAll()
    hasScannedBundles = false
}

// 设置中添加按钮
Button("重载图标") {
    LucideView.clearCache()
    NotificationCenter.default.post(name: .iconsReloaded, object: nil)
}
```

---

#### 6. 支持把 note 固化在某个屏幕上（不含浮球和主窗体）
**用户场景：**
- 多显示器环境下，希望便签只在特定屏幕显示

**解决方案：**
- `StickyNoteModel` 添加 `pinnedScreenId: String?` 属性
- `StickyNoteWindow.collectionBehavior` 移除 `.canJoinAllSpaces`
- 新增快捷键 `⌘⌥P` 固定到当前屏幕

```swift
// 快捷键注册
GlobalHotkeyManager.shared.register(
    key: "p", modifiers: [.command, .option], id: 5002
) { [weak self] in
    self?.pinCurrentNoteToCurrentScreen()
}
```

---

#### 7. 浮球经常"不见了"，需要排查有哪些方法会缩小
**问题描述：**
- 浮球莫名消失，用户不知道是什么原因

**解决方案：**
- 添加详细堆栈追踪日志
- 记录所有 `hide()` 和 `minimizeToBall()` 调用
- 便于排查问题根因

```swift
func hide() {
    print("[FloatingPanel] hide() called - stack trace:")
    Thread.callStackSymbols.forEach { print("  \($0)") }
    userHidden = true
    hideInternal(withAnimation: animationsEnabled)
}
```

## 🎯 核心改动详解

### 1. 卡片展开/折叠状态同步

**问题：** 两个独立状态导致不同步

**改动：**
```swift
// 之前：只切换卡片状态
expandedId = isExpanded ? nil : record.id

// 之后：同时处理原文状态
if isExpanded {
    expandedId = nil
    if showOriginalContent {
        showOriginalContent = false  // 收起原文
        // 发送通知清除父视图的记录
        NotificationCenter.default.post(...)
    }
}
```

---

### 2. 自定义 Tooltip 系统

**问题：** `.help()` 在高优先级窗口不显示

**改动：**
```swift
// 添加状态管理
@State private var tooltipText: String = ""
@State private var showTooltip: Bool = false

// 自定义显示
.overlay(Group {
    if showTooltip {
        Text(tooltipText)
            .font(.system(size: 11))
            .padding(.horizontal, 8)
            .padding(.vertical, 4)
            .background(Color.black.opacity(0.8))
            .cornerRadius(4)
            .position(...)
    }
})

// 触发显示
.onHover { hovering in
    if hovering {
        tooltipText = "提示文本"
        withAnimation { showTooltip = true }
    }
}
```

---

### 3. 屏幕固定机制

**核心改动：**
```swift
// 1. StickyNoteModel - 记录固定屏幕
var pinnedScreenId: String?

// 2. StickyNoteWindow - 移除跨空间行为
self.collectionBehavior = [.fullScreenAuxiliary]
// 之前: [.canJoinAllSpaces, .fullScreenAuxiliary]

// 3. StickyNoteManager - 快捷键固定
func pinCurrentNoteToCurrentScreen() {
    let screenNumber = screen.deviceDescription[NSDeviceDescriptionKey("NSScreenNumber")]
    notes[index].pinnedScreenId = screenNumber.stringValue
    saveNotes()
}
```

---

### 4. 撤销/重做系统

**架构设计：**
```swift
// 动作类型
enum HistoryAction {
    case delete(record: Record)
    case edit(recordId: UUID, oldContent: String, newContent: String)
    case toggleStar(recordId: UUID, oldState: Bool)
}

// 历史管理器
class HistoryManager {
    private var undoStack: [HistoryAction] = []
    private var redoStack: [HistoryAction] = []
    private let maxStackSize = 50

    func push(_ action: HistoryAction)
    func undo(recordStore: RecordStore)
    func redo(recordStore: RecordStore)
}
```

**集成点：**
- `RecordStore.delete()` - 推入 `.delete` 动作
- `RecordStore.updateContent()` - 推入 `.edit` 动作
- `KeyboardShortcutManager` - 处理 `Cmd+Z` 和 `Cmd+Shift+Z`

## ⚠️ 注意事项

1. **撤销优先级** - 文本编辑器撤销优先，应用级撤销仅在无编辑器聚焦时生效
2. **历史限制** - 最多 50 条历史，超出后自动清理最旧的
3. **屏幕固定** - 仅影响 StickyNote，不影响浮球和主窗体
4. **图标缓存** - Debug 模式下禁用缓存，每次重新加载
5. **截图缩略图** - zIndex 为 2500，高于预览层的 2000

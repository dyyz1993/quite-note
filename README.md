# Quite Note

基于SwiftUI的macOS剪切板历史记录和AI提炼工具

## 功能特性

- 📸 **专业截图 V2** - 静态全屏采集，支持多屏幕，吸附窗口识别
- 📜 **长图截取** - 实时滚动拼接预览，侧边智能控制面板
- 🎨 **自定义主题图标** - 剪切板+AI闪光设计
- 🤖 **AI 内容提炼** - 智能分析剪切板内容
- 📋 **剪切板管理** - 完整的历史记录追踪
- 🔧 **LucideIcons 优化** - 统一的图标渲染与加载机制
- 📱 **状态栏优化** - 极致精简的状态栏显示逻辑

## 系统要求

- macOS 12.0 或更高版本

## 安装方式

### 方式一：下载DMG安装包
1. 下载 `QuiteNote-1.0.0.dmg`
2. 双击挂载DMG文件
3. 拖拽应用到Applications文件夹
4. 首次运行可能需要在"系统偏好设置 > 安全性与隐私"中允许运行

### 方式二：直接使用应用包
1. 下载 `Quite Note.app`
2. 将其移动到Applications文件夹
3. 双击运行

## 使用说明

1. 应用启动后会出现在状态栏
2. 点击状态栏图标查看剪切板历史
3. 使用AI功能提炼剪切板内容

## 构建说明

本项目使用Swift Package Manager构建，支持GitHub Actions自动构建。

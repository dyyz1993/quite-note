```
│  外层 ZStack                                                 │
│  .coordinateSpace(name: "zstackSpace")                      │
│                                                              │

│  │  VStack                                             │     │
│  │                                                      │     │
│  │  ┌────────────────────────────────────────────┐    │     │
│  │  │  ScreenshotToolbar (约 60px)               │    │     │
│  │  │  .padding(.top, 30)                        │    │     │
│  │  └────────────────────────────────────────────┘    │     │
│  │                                                      │     │
│  │  ┌────────────────────────────────────────────┐    │     │
│  │  │  .padding(80, 40)                          │    │     │
│  │  │                                             │    │     │
│  │  │  ┌──────────────────────────────┐         │    │     │
│  │  │  │  Canvas                      │         │    │     │

```

## 坐标转换函数

```swift
func convertToCanvasCoordinates(_ point: CGPoint) -> CGPoint {
    return CGPoint(
        x: point.x - canvasFrameInZStack.minX,  // 自动获取的 X 偏移
        y: point.y - canvasFrameInZStack.minY   // 自动获取的 Y 偏移
    )
}
```

## 数据流向

```
1. Canvas 的 GeometryReader 获取位置
   └─ geometry.frame(in: .named("zstackSpace"))
      = CGRect(x: 80, y: 130, width: ..., height: ...)

2. 通过 PreferenceKey 传递到父视图
   └─ .preference(key: CanvasFramePreferenceKey.self,
                   value: geometry.frame(...))

3. ZStack 接收并保存
   └─ .onPreferenceChange(CanvasFramePreferenceKey.self) { frame in
         canvasFrameInZStack = frame  // = (80, 130, ...)
      }

4. 所有坐标转换使用这个动态值
   └─ convertToCanvasCoordinates(mouseLocation)
      = (mouseX - 80, mouseY - 130)
```

## 关键优势

| 特性 | 硬编码方式 | 动态方式 |
|------|-----------|---------|
| **精确性** | ❌ 需要手动计算所有偏移 | ✅ 系统自动计算 |
| **可维护性** | ❌ 修改 UI 需要更新代码 | ✅ 自动适应 |
| **健壮性** | ❌ 容易遗漏某些偏移 | ✅ 考虑所有因素 |
| **可读性** | ❌ 魔法数字不清晰 | ✅ 意图明确 |

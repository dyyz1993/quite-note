## 4. 放大镜特殊交互 ⚠️

**V2 实现有两个独立的拖拽目标**:

```
┌───────────────────────────────────┐
│ 选区                             │
│                                  │
│     ┌─────────┐                  │
│     │ 放大镜  │                  │
│     │ (圆圈)  │ ← 拖拽: 移动显示 │
│     └────┬────┘     位置         │
│          │                        │
│          │ 虚线                  │
│          ↓                        │
●        源点 ← 拖拽: 改变放大     │
│                  区域             │
└───────────────────────────────────┘

交互规则:
1. 点击选区 → 创建放大镜（默认右上角）
2. 拖拽放大镜圆圈 → 移动显示位置（不改变放大内容）
3. 拖拽源点（小圆圈）→ 改变放大区域（改变放大的内容）
4. 两个拖拽目标都限制在选区边界内
```

## 5. 文本工具特殊交互 ⚠️

**V2 实现有自动保存规则**:

```
文本工具交互:

1. 点击选区 → 创建文本框
   - 自动聚焦
   - 弹出键盘

2. 输入文本 → 实时编辑
   - 支持多行输入
   - 自动换行

3. 点击选区外部 → 完成编辑
   ⚠️ 空文本 → 自动删除
   ✅ 有文本 → 保存并退出

4. 按 ESC → 取消编辑
   - 清空文本（如果为空）
   - 退出编辑模式

5. 按 Enter → 保存文本
   - 保存并退出编辑模式
```

## 6. 裁剪限制 ✅

**所有标注元素超出选区边框会被裁剪**:

```
裁剪行为:

┌─────────────────────────────┐
│ 选区边界                   │
│ ┌───────────────────────┐  │
│ │ 矩形（部分超出）      │  │
│ │ ┌───┐                 │  │
│ │ └───┘← 超出部分被裁剪 │  │
│ └───────────────────────┘  │
└─────────────────────────────┘

规则:
- 矩形/箭头超出选区 → 裁剪
- 画笔超出选区 → 裁剪
- 文本超出选区 → 裁剪
- 放大镜 → 始终完整显示在选区内

实现:
- 使用 .clipShape(Rectangle())
- 保存时只裁剪选区范围
```
